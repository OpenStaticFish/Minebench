Desktop Chrome, Firefox, Safari or Edge with WebGL2. The world generates in a second or two, then WASD and the mouse do the rest.

Play Cubewild Read the controls
Run the game and this site locally 
bun install       # install game + site dependencies
bun run dev:all   # game → :5173, website → :5174 (Play works)

The website's Play buttons point at the game dev server automatically and open it in a new tab. For a single deployable folder instead, run bun run site:build:full, which builds the game into site/dist/play.
