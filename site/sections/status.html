Development status

An honest prototype

Cubewild is a compact creative-mode slice built by one developer. It is playable end to end, and it is not a finished commercial game.

Working today

  • Seeded procedural terrain with biome variation
  • Chunk streaming with an adjustable view distance
  • Caves, beaches, water and swimming
  • Block breaking and placing with a hotbar
  • Gravity movement, jumping, sprinting, creative flight
  • Sky, drifting clouds and distance fog
  • Settings that apply live, and in-game screenshots

Next up

  • Save and load worlds, so edits persist between sessions
  • Falling sand and leaf decay for more believable terrain
  • Audio: footsteps, block placement, ambient wind
  • A simple day/night cycle
  • Moving chunk meshing to a Web Worker for smoother streaming

Not planned yet

  • Survival progression, crafting and inventories
  • Multiplayer or dedicated servers
  • Touch controls and mobile support
  • Modding APIs or a level editor

Expect rough edges: water does not flow when you break a shoreline, trees float if you dig out the ground beneath them, and very fast travel across the map can still cause a brief hitch while chunks mesh.
