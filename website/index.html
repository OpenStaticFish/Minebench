A tiny sandbox that feels like a place.

Most voxel demos are flat fields of cubes. Vox Crest is a slice of world: beach sand gives way to plains, plains fold into hills, hills lift into stone-capped highlands. Trees punctuate the skyline, cave openings cut the slopes, and a low water plane ties it together. You start where the view reads — horizon, depth, and a clear next ridge to crest.

It’s creative mode only, deliberately. No survival loop to hide behind. Just movement that feels good, blocks that break and place honestly, and a camera that composes well for the next screenshot.

What you can actually do

Small feature list, fully playable. No bullet-point fiction.

⬢

Procedural terrain

FBM height + biome lerp (ocean → plains → hills → mountains) + domain warp. Same seed = same world. Seed is exposed and editable from the menu.

▥

Chunk columns

16×16 × 96-high columns, circular view radius 2–8 chunks. `ensureChunksAround` creates/removes meshes; rebuild only on edits. Geometry disposed on unload.

☁

Flight & gravity

Gravity 28, jump, and creative flight (double-tap Space / F). Fly-up `Space`, fly-down `Shift`/`Ctrl`, sprint with `Ctrl` while flying. Walking vs flying badge in HUD.

◰

Break & place

DDA voxel ray, wireframe highlight, hotbar 1–9 + wheel. Nine blocks: Grass, Dirt, Stone, Sand, Wood, Leaves, Water, Brick, Glass. No building inside self.

▲

Landforms you read

Beaches ring water, hills lift to stone highlands, trees (4–5 trunk + 3-leaf layers) on grass above sea, cave pockets and openings carved by 3D noise.

◐

Sky that screenshots well

Hemisphere + directional lights, Exp2 fog tied to view distance, two-layer box-cloud clusters drifting slowly. Horizon stays legible at any FOV.

How it’s built

For the curious — without overwhelming the front page.

For players

  • Runs in a modern desktop browser — no install. One `npm`/Bun install and you’re flying.
  • World feels hand-placed but is pure math: seeded value-noise, FBM, biome blends and warps.
  • Blocks are solid colours with vertex shading — grass tops pop, sand lines the shore, water reads translucent.

For developers

  • Game: Vite + Three.js + TypeScript + Bun. One `MeshLambert` for opaques + one for water per chunk, visible-face culling, AABB with axis-separated collision, DDA ray.
  • Site (this page): Vite + vanilla HTML/CSS/TS — same toolchain, no framework runtime. Ships < 15 kB CSS + ~2 kB JS. Good Lighthouse buds on low-power devices.
  • Seed + persistence: `mulberry32` + `hash2`, settings in `localStorage`, edits live but not yet persisted across reloads.

Status — honest prototype

This is not a finished commercial game. It’s a benchmark prototype built to feel complete in a narrow slice: generation, movement, editing, menus, and screenshots. No survival, no inventory beyond the hotbar, no multiplayer, no save yet. Block edits live for the session; reload reseeds the world.

Done

  • Procedural world with beaches, hills, mountains, caves, trees, water
  • Chunked meshing, fog, clouds, lights that screenshot well
  • Gravity + flight + collision + break/place + hotbar
  • Menu, HUD, pause, view/sensitivity/FOV, P screenshots
  • Game + site both Bun-run, built and previewable

Next, with more time

  • Greedy meshing + vertex AO + break particles
  • Flat water plane + simple reflections
  • Persistent edits via IndexedDB / export
  • Playwright CI that asserts screenshots exist
